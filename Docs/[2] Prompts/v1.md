# Original IQ — working prompt (v1)

Build **Original IQ**, a tutoring system.

## Stack

- `web-app/` — React + TypeScript + Vite
- `backend/` — Express + TypeScript
- Database — remote Supabase (connect later)
- Deploy — Vercel
- No Docker, Redis, Prisma, or mobile

## Architecture

- Layered backend: Route → Controller → Service → Repository → Supabase
- Feature-based web client; REST `/api/v1` only
- Roles: `SUPER` | `ADMIN` | `TUTOR` | `STUDENT`

## Keep

Existing UI kit, layout, auth screens, middleware, error handling, and layered module shape — adapt for tutoring domains as features are added.
